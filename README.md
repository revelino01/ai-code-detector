# AI Code Detector

A fast, lightweight statistical and heuristic analyzer that detects source code generated by Large Language Models (LLMs like ChatGPT, Claude, Copilot) versus human programmers.

Provides both a high-performance **Rust CLI / library** and a zero-dependency **standalone Python script**.

---

## How It Works

Detecting AI-generated source code relies on multi-dimensional statistical patterns and stylistic heuristics:

### 1. Commentary Style & Didactic Tone
* **Tautological Explanations**: LLMs frequently write comments that redundantly describe adjacent code (e.g. `// Calculate total price` immediately preceding `def calculate_total_price(...)`).
* **Instructional Framing**: Distinctive phrases like `helper function to`, `step 1:`, `base case:`, `loop through the array`, and `example usage:`.
* **Markdown Artifacts**: Structured Markdown docstrings (`### Arguments`, `- **param**:`, code blocks).
* **Human Quirks Discount**: The presence of colloquial comments (`TODO`, `FIXME`, `HACK`, `workaround`, informal notes) significantly reduces the AI probability score.

### 2. Identifier Naming & Vocabulary Distribution
* **Descriptive vs. Terse**: LLMs favor textbook multi-word identifiers (`user_session_token`, `calculate_discounted_rate`). Human developers frequently rely on idiomatic domain shorthands (`ctx`, `req`, `res`, `cfg`, `idx`, `buf`, `err`, `len`, `cb`).
* **Brevity Ratio**: Code where fewer than 10% of identifiers are short (<= 3 characters) correlates heavily with AI code generation.

### 3. Entropy & Line Burstiness
* **Burstiness**: Human writing is bursty—stretches of concise statements interspersed with dense expressions and uneven line lengths.
* **Coefficient of Variation ($CV = \sigma / \mu$)**: AI generation produces uniform pacing across code lines ($CV < 0.50$), whereas human code typically exhibits high line length variance ($CV > 0.75$).
* **Per-line Entropy Variance**: AI code maintains consistent character entropy per line.

### 4. Structural Regularity
* **Indentation Uniformity**: LLM outputs adhere strictly to mathematical indent steps with 0% human keystroke jitter.
* **Nesting Depth**: AI models strongly prefer shallow nesting (depth 1–3) combined with guard clauses (`if (!valid) return;`).

### 5. LLM Fingerprints & Templates
* Matches distinctive prompt traces such as `// Example usage:`, `// Driver code`, `your_api_key_here`, and standard algorithmic textbook templates.

## Installation

### Prerequisites
* Rust toolchain (1.75+ or newer)
* Optional: Python 3.8+ (for standalone script)

### Building the Rust binary
```bash
cargo build --release
# The compiled binary will be in ./target/release/ai-code-detector
```

---

## Usage

### Scanning a file or directory
```bash
# Scan a single file with verbose breakdown
ai-code-detector src/main.rs -v

# Scan an entire project recursively
ai-code-detector ./my-project

# Filter by specific extensions
ai-code-detector ./my-project --ext rs,py,ts,go
```

### Reading from standard input
```bash
cat snippet.py | ai-code-detector -
```

### CI/CD Quality Gate
Fail automated builds if any file exceeds a specified AI probability threshold:
```bash
ai-code-detector ./src --threshold 0.80
```

### JSON Output
Export full metric breakdowns for downstream reporting:
```bash
ai-code-detector ./src --json
```

---

## Python Standalone Script

A pure standard-library Python version is included in `python/detector.py`:

```bash
python3 python/detector.py ./my-project -v
python3 python/detector.py --json ./my-project
```

## Classification Levels

| Score Range | Classification | Description |
|---|---|---|
| **80% - 100%** | `HighConfidenceAi` | Strong convergence of didactic comments, textbook naming, and low burstiness |
| **60% - 79%** | `LikelyAi` | Substantial heuristic signals typical of LLM generation |
| **40% - 59%** | `MixedOrUncertain` | Mixed signals; plausible human-AI pair programming |
| **20% - 39%** | `LikelyHuman` | Idiomatic abbreviations, human comments (TODO/FIXME), bursty pacing |
| **0% - 19%** | `HighConfidenceHuman` | Distinctive human idiosyncrasies, irregular structure, shorthand |

---

## Limitations

Statistical code detection is probabilistic. Clean, well-documented code by an experienced human may exhibit patterns similar to AI, and prompt-engineered LLM output with informal comments can reduce detection confidence. This tool is designed as an assistive analysis signal rather than definitive attribution.
